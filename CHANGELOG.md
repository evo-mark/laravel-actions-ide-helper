# Changelog

All notable changes to `laravel-actions-ide-helper` will be documented in this file.

## 2.0.0 - 2026-11-02

### Breaking changes

- Dropped support for PHP versions below 8.4

### Changes

- Support `phpdocumentor/reflection` 7, `phpdocumentor/reflection-docblock` 6, Pest 5 and PHPUnit 13
- Add `paths` and `output` config options and `--path` / `--output` command options
- Remove `minimum-stability: dev`

- initial release
